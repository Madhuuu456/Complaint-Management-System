# Madhu Complaint Management System
HTML/CSS/JS frontend + Express.js backend + MySQL database.

## Run locally
1. Install Node.js (18+) and MySQL, and start MySQL.
2. `npm install`
3. Copy `.env.example` to `.env` and put your MySQL password in it.
4. `npm start` then open http://localhost:3000

create an account and add the complaint you will get respone of it later.
